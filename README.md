# Univers-Piano
Site éditorial dédié à l'univers du piano : son histoire, ses grands styles musicaux (classique, jazz, pop, musiques de film) et quelques figures marquantes de l'instrument, de Beethoven à Lang Lang.

Projet personnel réalisé pour apprendre à publier un site web de A à Z (code, GitHub, hébergement). Page web général sur le piano
